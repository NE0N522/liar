# Liar’s Bar Companion

Локальный компаньон для игры с настоящей колодой. Приложение ведёт игроков, ходы, вызовы на блеф и барабаны револьверов; карты остаются у игроков и физически не раздаются приложением.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес Vite, показанный в терминале. Чтобы проверить production-сборку локально:

```bash
npm run build
npm run preview
```

Для проверок:

```bash
npm run lint
npm test
npm run smoke
```

Первый запуск Playwright может потребовать браузер Chromium: `npx playwright install chromium`.

## Цвет и правда

В настройках партии включите «Правда по цвету». Цель стола тогда состоит из ранга и цвета. Например, для «6 красная» сыгранная шестёрка пик считается ложью, а шестёрка червей или бубен подходит. Если в последнем сыгранном наборе есть хотя бы одна неподходящая карта, заявление ложно; после вызова на блеф стреляет последний сыгравший. Если весь набор подходит, стреляет вызвавший. Джокер считается подходящим, кроме хаос-события «Запрет джокеров».

При включении цветового режима классический набор переключается на физический. По умолчанию он использует ранги 9–A; в поле рангов можно указать, например, `6, 7, 8, 9, 10, J, Q, K, A`, чтобы шестёрки участвовали в раздаче. Цвета карт в физической колоде представлены поровну красными и чёрными мастями.

Без цветового режима проверяется только ранг (либо один, либо два ранга, если выбран соответствующий режим).

## Что умеет приложение

- 2–8 игроков, настройка имён, порядка, размера руки и числа пуль.
- Классическая, физическая и настраиваемая колода; оценка баланса вероятности.
- Индивидуальные и общий барабаны, три типа револьвера, журнал партии и отмена последнего действия.
- Ручное подтверждение истины после вызова: приложение не видит физические карты.
- Настраиваемые хаос-события, таймер хода, статистика и повтор партии.
- Русский и английский интерфейс, адаптивная раскладка, звук, вибрация, упрощённые эффекты и доступные клавиатурные элементы управления.
- Устанавливаемое PWA и офлайн-экран; 3D-сцена подгружается отдельно и имеет SVG-резерв, если WebGL недоступен или включён упрощённый режим.

## Технические допущения

- Приложение сохраняет состояние партии и настройки в локальном хранилище браузера, поэтому игру можно продолжить после перезагрузки страницы на том же устройстве. Синхронизации между устройствами нет.
- Карты не сканируются. После вызова игроки сами сверяют последнюю сыгранную карту или набор и нажимают «Он врал» либо «Говорил правду».
- Цвет в цветовой цели означает красную или чёрную масть. В физической колоде черви/бубны красные, пики/трефы чёрные.
- Результат выстрела вычисляется игровым движком заранее; сцена показывает результат и не меняет его.
- Web Audio запускается после первого взаимодействия пользователя, а блокировка экрана зависит от поддержки браузера.

## Сборка и публикация

`npm run build` создаёт статический сайт в `dist/`. В репозитории настроен GitHub Actions workflow: при push в `main` он собирает приложение для пути `/liar/` и публикует `dist/` на GitHub Pages. Адрес сайта: <https://ne0n522.github.io/liar/>. Для первой публикации в настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**.

PWA Service Worker и manifest формируются при production-сборке. Тяжёлая 3D-сцена загружается отдельно, когда она нужна, и кэшируется при первом открытии. Для Vercel, Netlify или другого статического хостинга используйте обычную команду `npm run build` и настройте SPA fallback на `index.html`.
